# Представления

## DeviceListView  
Представление для работы с устройствами (список и создание).  
Методы:  
- GET: Возвращает список всех устройств.  
- POST: Создает новое устройство.  

---

## DeviceDetailView  
Представление для работы с конкретным устройством (детали и удаление).  
Методы:  
- GET: Возвращает информацию о конкретном устройстве по его device_id.  
- DELETE: Удаляет устройство по его device_id.  

---

## SpeedRecordListView  
Представление для работы с записями скорости (список и создание).  
Методы:  
- GET: Возвращает список всех записей скорости.  
- POST: Создает новую запись скорости.  

---

## SpeedRecordDetailView  
Представление для работы с конкретной записью скорости (детали и удаление).  
Методы:  
- GET: Возвращает информацию о конкретной записи скорости по её record_id.  
- DELETE: Удаляет запись скорости по её record_id.
