# Модели

## Question  
Модель для хранения вопросов.  
- question_text: Текст вопроса (CharField).  

Методы:  
- __str__(): Возвращает текст вопроса.  

---

## Choice  
Модель для хранения вариантов ответов.  
- choice_text: Текст варианта ответа (CharField).  

Методы:  
- __str__(): Возвращает текст варианта ответа.  

---

## Device  
Модель для устройства.  
- name: Название устройства (CharField).  

Методы:  
- __str__(): Возвращает название устройства.  

---

## SpeedRecord  
Модель для записи скорости и точности.  
- device: Устройство, к которому относится запись (ForeignKey).  
- speed: Скорость ввода в словах в минуту (IntegerField).  
- accuracy: Точность ввода в процентах (FloatField).  
- timestamp: Время создания записи (DateTimeField).  

Методы:  
- __str__(): Возвращает строковое представление записи с информацией об устройстве, скорости и точности.
